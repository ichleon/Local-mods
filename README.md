# Local-mods

Öffentliche Mod-Sammlung für die geheime `local`-Ansicht von MODBLOCK.

- Lege `.jar`-Dateien in `local-mods/` ab.
- Unterordner in `local-mods/` werden in MODBLOCK als Ordner-Karten angezeigt und können verschachtelt werden.
- Downloads erfolgen direkt von GitHub; es gibt keinen Upload aus MODBLOCK.
